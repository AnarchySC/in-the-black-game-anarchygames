Identification
--------------
The shipped Codex.ttf carries no copyright, designer, vendor or license record
in its name table - it arrived from FontSpace that way, as a loose .ttf rather
than the zip. Every other font downloaded from FontSpace in this collection
ships an info.txt naming its license and source URL; taking the direct file
link skips it. Identification here is by the font's internal head-table
creation date (2023-03-28), which matches the listing's release date exactly,
plus the family name, the LITE character set, and the existence of an Italic.

Assessment
----------
Commercial use is explicitly granted, so using this typeface in the game -
including a paid release - is within the licence.

The "no redistribution or re-upload of the font files" clause is aimed at
distributing the font AS a font: re-uploading it to font aggregators, or
reselling it. A game that embeds a typeface in order to draw text is not a
font distribution channel, the same way a PDF with an embedded font is not.
Nobody has an incentive to extract it from here either - the LITE cut is a
free download from the source.

So: no action needed. Do NOT try to harden this. Subsetting the font to only
the glyphs used would be worse than doing nothing, because "converting the
font into other formats for distribution" is the one term explicitly
prohibited. Base64-embedding it is not protection when the file is in a public
repo anyway.

If CODEX ever becomes worth paying for on its own merits, the full family is on
Creative Fabrica - but as an upgrade, not a remedy.

This font file is also committed in several of the owner's other public repos.
Same assessment applies to all of them.
